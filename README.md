
# Análisis de embudo y retención para MercadoLibre  🚛

>[!NOTE]
>PROYECTO REALIZADO EN TRIPLETEN
>
Necesitamos entender en qué etapa del proceso perdemos usuarios y cómo podemos mejorar su retención a lo largo del tiempo


## Objetivos 🎯

1. Construir embudos multietapa en SQL usando CTEs.

2. Calcular tasas de conversión entre pasos y detectar caídas.

3. Analizar la retención de usuarios por cohortes.   

4. Simular mejoras en conversión o retención.

5. Validar resultados y comunicar hallazgos ejecutivos. 


## Proceso ✏️

- Explorar el esquema y los datos base.
- Construir el embudo de conversión.
- Calcular tasas y caídas.
- Analizar retención y cohortes.
- Simular mejoras y redactar el informe ejecutivo.


## Principales Hallazgos  💯 ✔️

El proceso con mayor pérdida de usuarios en el funnel se registra en la etapa de agregar un producto al carrito, donde se encontró un abandono del 85% en el embudo general. Para el embudo por país, se observó un promedio de abandono del 85%.
